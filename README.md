# ledgehost

A Linux (Ubuntu / X11) host that speaks a wire protocol compatible with an
existing iPad remote-streaming client, so the stock client can connect to a
Linux desktop (Xfce assumed).

Status: Phase -1 (desk research). No implementation yet.

Codename: `ledgehost` — a neutral name chosen for this project. It is not
affiliated with the upstream client project.

License: to be decided before any public release. Upstream code, if reused,
is Apache-2.0 and its NOTICE will be preserved.
